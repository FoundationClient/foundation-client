# Foundation Client

A performance and cosmetics client for **Minecraft: Java Edition** (Fabric, 1.21.11).

Foundation is built to make Minecraft run smoother and look cleaner, without giving anyone an unfair advantage. Every feature is client-side and designed to be allowed on public servers.

> **Status:** early development. No public release yet.

## Features

**Performance**
- Live stats overlay (F6): FPS, 1% lows, frame time
- Built-in 60-second benchmark (F7) that saves results to CSV
- *In progress:* entity culling, distance-based entity detail, particle budget, and an adaptive tuner that holds your target FPS automatically

**Interface**
- A completely redesigned main menu with your own skin on display
- Every Minecraft screen restyled in Foundation's clean dark look
- No menu panorama or background music, so the game uses less of your PC on menus

**Accounts & skins**
- In-game account switcher: add your Microsoft accounts once and switch between them without restarting
- Skin switcher: preview skins on your player and apply them in one click
- Sign-in happens on Microsoft's own page (microsoft.com/link). Foundation never sees your password.
